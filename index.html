📱 Stouchi

Gestion Intelligente des Dépenses Étudiantes

Flutter 3.9.2+ Version 2.0 Octobre 2025 100% Responsive

Prenez le contrôle de vos finances

Stouchi est une application mobile complète et sécurisée conçue spécialement pour les étudiants souhaitant gérer efficacement leurs dépenses quotidiennes.

Avec son interface moderne, son système de sécurité par code PIN et ses fonctionnalités de suivi avancées, gérer votre budget n'a jamais été aussi simple et ludique.

🚀 Installation

Étapes d'installation :

  1. Cloner le projet : git clone https://github.com/MontassarTayachi/Stouchi.git
  2. Installer les dépendances : flutter pub get
  3. Lancer l'application : flutter run

Prérequis : Flutter SDK 3.9.2+ et un émulateur Android/iOS ou appareil physique.
